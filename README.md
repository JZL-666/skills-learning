# skills-learning · 驾驭 AI Agent 的工程内功

一套基于 [mattpocock/skills](https://github.com/mattpocock/skills) 真实源码的中文自学课程（9 课），把资深工程师"控制 AI 编程代理"的方法论拆解给新手：四大失控模式、grilling 拷问、共享语言（DDD）、深模组、12 种代码坏味道、TDD 红绿循环、to-spec / to-tickets / implement 工作流主干道、writing-great-skills 写作原则。

**在线阅读**：开启 GitHub Pages 后访问 `https://<username>.github.io/skills-learning/`

## 特点

- 📖 每课以 skills 仓库**第一手源码**为教材，所有英文引用附中文对照
- ✅ 每课配即时反馈的随堂测验（点选项立即判分讲解）
- 🧭 数据驱动导航：目录页 / 上一课 / 下一课 / 跳转下拉框，全部由 `assets/toc-data.js` 单一数据源渲染
- 📚 附术语表（20+ 指引词速查）与视频笔记

## 课程地图

| 阶段 | 课程 |
|---|---|
| 阶段 0 · 世界观 | 01 这套 skills 到底在防什么？ |
| 阶段 1 · 拷问的艺术 | 02 逐句拆解 grilling ｜ 03 grill-with-docs 与共享语言 |
| 阶段 2 · 工程内功 | 04 深模组 ｜ 05 12 种代码坏味道 ｜ 06 TDD 红绿循环 |
| 阶段 3 · 工作流主干道 | 07 to-spec 与 to-tickets ｜ 08 implement |
| 阶段 4 · 终极检验 | 09 writing-great-skills：写出你自己的 skill |

## 本地使用

无需构建，克隆后直接用浏览器打开 `index.html` 即可。
